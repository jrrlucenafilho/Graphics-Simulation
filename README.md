## Instruções de como compilar e executar

### Dependências

- Compilador **g++** (ou clang++)
- **OpenGL** (`libgl1-mesa-dev`)
- **GLU** (`libglu1-mesa-dev`)
- **FreeGLUT** (`freeglut3-dev`)

### Compilar

```bash
g++ -o graphics_simulation main.cpp -lGL -lGLU -lglut
```

### Executar

```bash
./graphics_simulation
```
